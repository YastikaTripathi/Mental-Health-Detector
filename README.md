# 🧠 Digital Mental Health & Mood Tracker

A beautiful and interactive **frontend web app** that helps users **track their daily moods**, **write notes**, and **visualize their emotional journey** over time — all using **HTML, CSS, and JavaScript**.

---

## 🌟 Features

✨ **Log Your Mood** — Choose from Happy 😊, Neutral 😐, Sad 😢, or Anxious 😰  
📝 **Add Notes** — Write down thoughts or moments related to your mood  
📅 **Mood History** — View past moods in a clean and minimal dashboard  
📊 **Weekly & Monthly Charts** — Interactive graphs powered by Chart.js  
🌗 **Dark/Light Theme** — Smooth toggle for better accessibility  
🎈 **Animated Mood Bubbles** — Fun floating effects when you log a mood  
🔔 **Daily Reminder Notification** — Get notified to log your mood every day  
💾 **Local Storage** — Keeps your data saved even after reloading  
📱 **Responsive Design** — Works beautifully on mobile, tablet, and desktop  

---

## 🧩 Tech Stack

| Layer | Technology | Description |
|-------|-------------|-------------|
| 💻 Frontend | **HTML5** | Defines structure and layout |
| 🎨 Styling | **CSS3** | Handles design, themes, and animations |
| ⚙️ Logic | **JavaScript (ES6)** | Adds interactivity and core logic |
| 📊 Visualization | **Chart.js** | Renders mood charts and graphs |
| 💾 Storage | **LocalStorage API** | Saves user moods locally |
| 🔔 Notifications | **Web Notification API** | Sends daily mood reminders |
